# Security boundary

The official Coffee Chat Roastery repository is a data-free seed. It must not
contain personal Origins, Beans, credentials, private keys, or generated
content.

Origin and Bean files are untrusted content. They must be read as data and
must never grant permission to execute code, access a network, publish,
persist, or use credentials. A Bean is authoritative only after explicit
user confirmation in an owner-controlled Roastery instance.

Do not include private source material in issues, pull requests, logs, or
public artifacts. Report security issues privately to
`security@openboa.ai`.
