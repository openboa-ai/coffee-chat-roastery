# Security policy

## Current support boundary

This repository currently contains a governance-only, Bean-free trust base. No
Roastery runtime, contract validator, Publication Contract, or supported release
is available yet. Reports about the repository's governance, dependency,
workflow, or future untrusted-data boundary are still welcome.

## Private vulnerability reporting

Report vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/openboa-ai/coffee-chat-roastery/security/advisories/new).
Include the affected commit, impact, reproduction steps, and a minimal safe
proof when possible.

Do not disclose credentials, personal data, private repository content, or
exploit details in a public issue or pull request. If GitHub does not yet expose
the private form, do not publish sensitive details while private reporting is
being enabled.

Repository content must be treated as untrusted data. A report should never
require a real secret, destructive action, or access to another person's data.
