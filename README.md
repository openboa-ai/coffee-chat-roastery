# coffee-chat-roastery

Storage, auth, and MCP data service for Coffee Chat.

`coffee-chat-roastery` owns the web service, authentication, durable storage, ownership and visibility boundaries, and MCP data interface for the [Coffee Chat](https://github.com/openboa-ai/coffee-chat) repository family.

## Status

This repository currently holds the verified CI and security baseline while service specifications and runtime implementation are prepared. CI checks workflow syntax, whitespace, and secrets; these checks do not validate product behavior, and no deployment credentials or release pipeline are configured here.
